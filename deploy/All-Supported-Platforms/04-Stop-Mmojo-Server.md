## 04. Stop Mmojo Server
### About this Step
In this step, you will stop Mmojo Server. 

---
### Stop Mmojo Server
When you're done using Mmojo Server, you should stop it. Just close the Terminal window.

You can also keep it running, but note that it consumes enough RAM to load the model file and little bit more.

---
### Uninstall Mmojo Server
You didn't really "install" it. Just throw the folder in the Trash or Recycle Bin, and you're done. Mmojo Server leaves no footprints. Your privacy is important!
