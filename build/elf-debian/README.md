## Build Mmojo Server for Debian Linux
### About this Guide
In this guide, you will build ELF executables of Mmojo Server, Mmojo RPC Server, and llama.cpp targets for your computer's CPU family — x86_64 or aarch64 (arm64). You will test your Mmojo Server and Mmojo RPC Server builds. You will package your Mmojo Server and Mmojo RPC Server for later use or external deployment.

**Get Started:**
