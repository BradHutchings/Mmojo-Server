## 24. Test OpenClaw
### About this Step
You perform a few tests to demonstrate that OpenClaw is using your Mmojo Server for it's large language model (LLM) server.

*As of this writing, the OpenClaw user interface feels flakey, especially when used with a small local LLM. There are a lot of things wrong with this project. I like to think they will eventually sort some out. -Brad 2026-02-02*
