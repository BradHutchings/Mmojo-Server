## Build Mmojo Server for Windows
**THIS GUIDE IS A WORK IN PROGRESS.**
### About this Guide
In this guide, you will build PE executables of Mmojo Server, Mmojo RPC Server, and llama.cpp targets for x86 and ARM.

These build steps should be performed with macOS. Please prepare your macOS environment by working through this deploy recipes:
- [Deploy Mmojo Server on Windows](/deploy/Windows/README.md)
