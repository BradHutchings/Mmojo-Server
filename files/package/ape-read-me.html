Thank You!

Thank you for your interest in Mmojo Server, the easiest private LLM server in the world!

If you have a computer powered by an x86_64 CPU or an ARM64 CPU, you can run Mmojo Server and use a large language model privately without "instaling" anything on your computer.

I recommend 8 GB RAM so you can run a small LLM comfortably and do other work.

Mmojo Server is a derivative of llama.cpp, which I've customized to make more usable by regular folks.

Start Mmojo Server

Windows Users:
Double-click 1-mmojo-server-ape-performant.exe. A Terminal window will open and you will see it doing work. If it stops or complains about an error, close the Terminal window and double-click 3-mmojo-server-ape-compatible.exe.

Mac Users:
Double-click 2-mmojo-server-ape-performant. A Terminal window will open and you will see it doing work. If it stops or complains about an error, close the Terminal window and double-click 4-mmojo-server-ape-compatible. That should only happen with Intel CPU Macs.

Raspberry Pi Users:
Double-click 3-mmojo-server-ape-performant.exe. A Terminal window will open and you will see it doing work.

Other Linux Users:
GNOME Files wants to launch these in the background, where you can't see that it's running and can't stop the Mmojo Server process by closing a window. Right-click 5-GNOME-Files-Start-performant.sh. At least one Terminal window will open and you will see it doing work. If it stops or complains about an error, close the Terminal window and double-click 6-GNOME-Files-Start-compatible.sh

Connect with your Browser

Once you have Mmojo Server running in a Terminal window, click one of these files to connect to with your web browser:

  • Connect-to-Mmojo.html - Use our humane Mmojo Complete user interface to use the LLMs without pretending you're chatting with a quasi-intelligent robot.
  • Chat-with-Mmojo.html - If you have to pretend you're chatting with a robot, Mmojo Server offers a familiar chat interface too.

Stop Mmojo Server

Close your web browser window.

Close the Terminal window.

You're done with Mmojo Server. Nobody will even know you ran it. Wasn't that easy?
