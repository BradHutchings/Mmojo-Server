About Mmojo Server

I make the free Mmojo Server software that runs privately on your computer. Use it as a replacement for cloud LLMs like ChatGPT, Claude, or Grok.

--
Brad Hutchings
brad@Mmojo.net

  • Mmojo Server is private. None of your data is sent to the cloud. EVER.
  • The default Mmojo Complete user interface is humane, simple, and powerful. You do not have to pretend to have a conversation with a robot to get answers or assistance. It is truly collaborative, with a rollback feature that lets the LLM complete from any point in previous completion or editing.
  • The more traditional user interface Mmojo Chat is very simple, and private. Yet, it is powerful enough to interview you, tease an idea out of you, and summarize it!
  • Mmojo Server requires no signup and no installation. You can even copy it to a fast USB 3.2 thumb drive and use it when needed on any computer.
  • Mmojo Server is open source, based on llama.cpp. I do this so competent developers can verify my claims of privacy. They’re also welcome to build their own. It has the easiest to follow build and deployment instructions you’ll find in any open source project.
