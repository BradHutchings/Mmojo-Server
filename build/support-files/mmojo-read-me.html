About Mmojo Server

  • Mmojo Server is private. None of your data is sent to the cloud. EVER. I do not want to see your cues and prompts.
  • The default Mmojo Complete user interface is humane, simple, and powerful. You do not have to pretend to have a conversation with a robot to get answers or assistance. It is truly collaborative, with a rollback feature that lets the LLM complete from any point in previous completion or editing.
  • The more traditional Mmojo Chat user interface is very simple — and private. Yet, it is powerful enough to interview you, tease an idea out of you, and summarize it!
  • Mmojo Server requires no signup and no installation. You can copy it to a fast USB 3.2 thumb drive and use it when needed on any computer with a USB port.
  • This free build of Mmojo Server uses CPU inference. It is not accelerated by your GPU. My GPU accelerated builds are a paid product. Email me if you're interested in one for your computer and GPU, including for Apple Silicon (M-series processors). I will have them available for direct purchase on Mmojo.net in the future.
  • Get the latest Mmojo Server from Mmojo.net.
  • Read the Mmojo Server FAQ.
  • If you need my assistance with setup issues, I offer a paid 30 minute Zoom or email thread. You may purchase Mmojo Server Setup Assistance with PayPal.
  • Mmojo Server is open source, based on llama.cpp. I do this so competent developers can verify my claims of privacy. Developers are also welcome to build their own. Mmojo Server has the easiest to follow build and deployment instructions you will find in an open source project. I do not accept pull requests for this repo. It is not a community project.
